# Welcome

The SOLIDWORKS Visualize Add-in API:

- allows you to automate the photorealistic rendering of SOLIDWORKS Design models using SOLIDWORKS Visualize. The SOLIDWORKS Visualize Add-in is a key component in the render automation workflow. See [Getting Started](GettingStarted.html) for details about loading and using the SOLIDWORKS Visualize Add-in.

- invokes the render of a SOLIDWORKS Design file, but also translates it to create a SOLIDWORKS Visualize project file with the same geometry, appearances, camera, etc. that are employed when importing and rendering a SOLIDWORKS Design assembly or part using the SOLIDWORKS Visualize user interface.

- works exclusively with SOLIDWORKS Visualize, a photorealistic rendering application that uses lighting, shading, backgrounds, and textures to give SOLIDWORKS Design models the appearance of photographic realism. For more information about SOLIDWORKS Visualize, see the **SOLIDWORKS Web Help > SOLIDWORKS Visualize and SOLIDWORKS Visualize Connected** topics.
