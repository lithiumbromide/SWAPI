# GetArguments Method (ILispFunction)

Gets the arguments from LISP and returns the corresponding array of LISP parameters passed to this LISP function.

## Syntax

### Visual Basic

```vb
Function GetArguments() As System.Object
```

### C#

```csharp
System.object GetArguments()
```

### JScript

```
function GetArguments() : System.Object;
```

### Managed Extensions for C++

```
System.Object* GetArguments();
```

### C++/CLI

```cpp
System.Object^ GetArguments();
```

### Return Value

Array of [LISP parameters](Interop.dsAutomation~Interop.dsAutomation.ILispParameter.html) passed to this LISP function
