# IColorPicker Interface

Allows access to the DraftSight color picker, which assigns [LineColors](Interop.dsAutomation~Interop.dsAutomation.IColor.html) to drawing entities directly, by [Layer](Interop.dsAutomation~Interop.dsAutomation.ILayer.html), or by [Block](Interop.dsAutomation~Interop.dsAutomation.IBlockDefinition.html).
