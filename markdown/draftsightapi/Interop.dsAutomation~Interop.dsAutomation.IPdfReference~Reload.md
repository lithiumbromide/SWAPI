# Reload Method (IPdfReference)

Reloads this PDF reference.

## Syntax

### Visual Basic

```vb
Sub Reload()
```

### C#

```csharp
void Reload()
```

### JScript

```
function Reload();
```

### Managed Extensions for C++

```
void Reload();
```

### C++/CLI

```cpp
void Reload();
```

## Remarks

Use this method to:

- reload a previously [unloaded PDF image](Interop.dsAutomation~Interop.dsAutomation.IPdfReference~Unload.html).
  - or -
- update the PDF image to its most recently saved state.
