# HideLeadingZeroes Property (IDimensionStyleToleranceOptions)

Gets or sets whether to hide or show leading zeroes for Dimension geometric tolerances.

### Visual Basic



### C++/CLI

```cpp

   System.bool get();
   void set (    System.bool value);
```

### Property Value

True to hide leading zeroes, false to show them
