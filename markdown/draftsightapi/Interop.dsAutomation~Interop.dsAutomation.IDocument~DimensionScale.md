# DimensionScale Property (IDocument)

Gets or sets the scale factor based on the ratio between the current Viewport and the drawing Sheet.

## Syntax

### Visual Basic

```vb
Property DimensionScale As System.Double
```

### C#

```csharp
System.double DimensionScale {get; set;}
```

### JScript

```
function get,set DimensionScale : System.double
```

### Managed Extensions for C++

```
__property System.double get_DimensionScale();
__property void set_DimensionScale(
   System.double value
);
```

### C++/CLI

```cpp
property System.double DimensionScale {
   System.double get();
   void set (    System.double value);
}
```

### Property Value

Scale factor based on the ratio between the current Viewport and the drawing Sheet
