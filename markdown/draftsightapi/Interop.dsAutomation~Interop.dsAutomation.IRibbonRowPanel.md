# IRibbonRowPanel Interface

Allows access to a ribbon row panel.

## Syntax

### Visual Basic

```vb
Public Interface IRibbonRowPanel
```

### C#

```csharp
public interface IRibbonRowPanel
```

### JScript

```
public interface IRibbonRowPanel
```

### Managed Extensions for C++

```
public __gc __interface IRibbonRowPanel
```

### C++/CLI

```cpp
public interface class IRibbonRowPanel
```

## Remarks

Only one ribbon row panel is permitted on a [ribbon row](Interop.dsAutomation~Interop.dsAutomation.IRibbonRow.html). Use the ribbon row panel to organize up to three ribbon rows in a vertical line.
