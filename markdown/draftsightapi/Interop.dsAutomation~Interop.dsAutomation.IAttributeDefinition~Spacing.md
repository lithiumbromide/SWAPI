# Spacing Property (IAttributeDefinition)

Gets or sets the aspect ratio (i.e., the width of the characters in relation to the [height](Interop.dsAutomation~Interop.dsAutomation.IAttributeDefinition~Height.html)) for the BlockAttribute definition.
