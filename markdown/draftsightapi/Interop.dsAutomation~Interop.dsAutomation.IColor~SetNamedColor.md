# SetNamedColor Method (IColor)

Sets the color to the named LineColor or TextColor.

## Syntax

### Visual Basic

```vb
Sub SetNamedColor( _
   ByVal NamedColor As dsNamedColor_e _
)
```

### C#

```csharp
void SetNamedColor(
   dsNamedColor_e NamedColor
)
```

### JScript

```
function SetNamedColor(
   NamedColor : dsNamedColor_e

```

### Managed Extensions for C++

```
void SetNamedColor(
   dsNamedColor_e NamedColor
)
```

### C++/CLI

```cpp

   dsNamedColor_e NamedColor
```
