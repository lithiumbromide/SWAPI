# RemoveAnnotation Method (ILeader)

Removes the annotation from the Leader.

## Syntax

### Visual Basic

```vb
Sub RemoveAnnotation()
```

### C#

```csharp
void RemoveAnnotation()
```

### JScript

```
function RemoveAnnotation();
```

### Managed Extensions for C++

```
void RemoveAnnotation();
```

### C++/CLI

```cpp
void RemoveAnnotation();
```

## Remarks

The type of annotation that you can remove from a Leader is:

- [Block instance,](Interop.dsAutomation~Interop.dsAutomation.IBlockInstance.html)
- [Note](Interop.dsAutomation~Interop.dsAutomation.INote.html), or
- [Geometric Tolerance](Interop.dsAutomation~Interop.dsAutomation.ITolerance.html)
