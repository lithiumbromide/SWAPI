# UpsideDown Property (ISimpleNote)

Gets or sets whether the SimpleNote is displayed upside down.

### C++/CLI

```cpp

   System.bool get();
   void set (    System.bool value);
```

### Property Value

True to display the SimpleNote upside down, false to display it right-side up
