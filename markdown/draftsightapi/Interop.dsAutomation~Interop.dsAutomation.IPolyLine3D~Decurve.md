# Decurve Method (IPolyLine3D)

Reverts the 3D PolyLine curve, created by [IPolyLine3D::Spline](Interop.dsAutomation~Interop.dsAutomation.IPolyLine3D~Spline.html), to its original vertices.

## Syntax

### Visual Basic


### C#

```csharp

```

### JScript

```
function Decurve() : System.boolean;
```

### Managed Extensions for C++

```

```

### C++/CLI

```cpp
System.bool Decurve();
```

### Return Value

True if the 3D PolyLine curve reverts to its original vertices, false if not
