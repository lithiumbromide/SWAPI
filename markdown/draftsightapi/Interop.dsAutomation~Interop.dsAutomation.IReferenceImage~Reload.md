# Reload Method (IReferenceImage)

Reloads the Referenced image.

## Syntax

### Visual Basic

```vb
Sub Reload()
```

### C#

```csharp
void Reload()
```

### JScript

```
function Reload();
```

### Managed Extensions for C++

```
void Reload();
```

### C++/CLI

```cpp
void Reload();
```

## Remarks

Use this method to:

- reload a previously [unloaded Referenced image](Interop.dsAutomation~Interop.dsAutomation.IReferenceImage~Unload.html).
  - or -
- update the Referenced image to its most recently saved state.
