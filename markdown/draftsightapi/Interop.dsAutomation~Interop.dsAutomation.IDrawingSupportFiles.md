# IDrawingSupportFiles Interface

Allows access to the options that get and set default paths and file names for these drawing-support files: alternate font, drawing, drawing template, external references, font mapping, library, [LineStyle](Interop.dsAutomation~Interop.dsAutomation.ILineStyle.html), and [RichLineStyle](Interop.dsAutomation~Interop.dsAutomation.IRichLineStyle.html).
