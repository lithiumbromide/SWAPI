# SetPosition Method (ITable)

Sets the point in the drawing where to insert the Table.

### Parameters

- `X`: x coordinate of the point where to insert the Table
- `Y`: y coordinate of the point where to insert the Table
- `Z`: z coordinate of the point where to insert the Table
