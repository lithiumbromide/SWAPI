# Spacing Property (IAttributeInstance)

Gets or sets the aspect ratio (i.e., the width of the characters in relation to the [height](Interop.dsAutomation~Interop.dsAutomation.IAttributeInstance~Height.html)) for the BlockAttribute instance.
