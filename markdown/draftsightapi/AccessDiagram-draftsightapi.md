# Access Diagram

DraftSight API access diagrams:

- are graphical representations depicting access to DraftSight API objects.
- require that PDF reader software be installed on your computer.
- allow standard PDF actions (e.g., scroll, zoom in and out, search, print, etc.).

Each interface's Help topic contains an **Access Diagram** section. Click the link in this section to open that interface's access diagram.

Objects shown:

- left of the object whose access diagram you are viewing are the objects that return that object. At the beginning of DraftSight API access is the [Application](Interop.dsAutomation~Interop.dsAutomation.IApplication.html) object; thus, no objects appear to the left of that object.
- right of the object whose access diagram you are viewing are returned by that object.

Within any access diagram, click a link to display that access diagram. To return to the Help topic from which you displayed its access diagram, click the **Back** button in the Help window.

**NOTE:** Access diagrams are not displayed when using Qt Assistant to view the DraftSight API Help, because Qt Assistant does not support embedded PDF files.
