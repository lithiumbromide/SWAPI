# Visible Property (ISimpleNote)

Gets or sets whether to show the SimpleNote in the drawing.

### C++/CLI

```cpp

   System.bool get();
   void set (    System.bool value);
```

### Property Value

True to show the SimpleNote in the drawing, false to hide it
