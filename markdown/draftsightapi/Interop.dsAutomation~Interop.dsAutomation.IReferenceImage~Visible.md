# Visible Property (IReferenceImage)

Gets or sets whether to show the Referenced image in the drawing.

```

```

### C++/CLI

```cpp
property System.bool Visible {
   System.bool get();
   void set (    System.bool value);

```

### Property Value

True to show the Referenced image in the drawing, false to hide it
