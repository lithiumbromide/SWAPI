# UpsideDown Property (IAttributeDefinition)

Gets or sets whether to display the BlockAttribute definition upside down.

## Syntax

### Visual Basic

```vb

```

### C#

```csharp

```

```

```

```
   System.bool value

```

### C++/CLI

```cpp
property System.bool UpsideDown {
   System.bool get();
   void set (    System.bool value);
}
```

### Property Value

True to display the BlockAttribute definition upside down, false to display it right-side up
