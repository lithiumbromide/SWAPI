# Select Method (IAttributeInstance)

Adds or removes the selected BlockAttribute instance to or from the current selection set.

## Syntax

### Visual Basic

```vb
Function Select( _
   ByVal SelectFlag As System.Boolean _
) As System.Boolean
```

### C#

```csharp
System.bool Select(
   System.bool SelectFlag
)
```

### JScript

```
function Select(
   SelectFlag : System.boolean
) : System.boolean;
```

### Managed Extensions for C++

```
System.bool Select(
   System.bool SelectFlag
)
```

### C++/CLI

```cpp
System.bool Select(
   System.bool SelectFlag
)
```

### Parameters

- `SelectFlag`: True to add the selected BlockAttribute instance to the current selection set, false to remove the selected BlockAttribute instance from the current selection set

### Return Value

True if the selected BlockAttribute instance was added to or removed from the current selection set, false if not
