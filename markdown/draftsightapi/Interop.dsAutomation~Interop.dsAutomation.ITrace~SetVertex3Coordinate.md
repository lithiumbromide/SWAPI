# SetVertex3Coordinate Method (ITrace)

Sets the x, y, and z coordinates for the third vertex for this Trace.

## Syntax

### Visual Basic

```vb
Sub SetVertex3Coordinate( _
   ByVal X As System.Double, _
   ByVal Y As System.Double, _
   ByVal Z As System.Double _
)
```

### C#

```csharp
void SetVertex3Coordinate(
   System.double X,
   System.double Y,
   System.double Z
)
```

### JScript

```
function SetVertex3Coordinate(
   X : System.double,
   Y : System.double,
   Z : System.double
);
```

### Managed Extensions for C++

```
void SetVertex3Coordinate(
   System.double X,
   System.double Y,
   System.double Z
)
```

### C++/CLI

```cpp
void SetVertex3Coordinate(
   System.double X,
   System.double Y,
   System.double Z
)
```

### Parameters

- `X`: x coordinate of the third vertex
- `Y`: y coordinate of the third vertex
- `Z`: z coordinate of the third vertex
