# UpsideDown Property (ITextStyle)

Gets or sets whether to display the text of the TextStyle upside down.

## Syntax

### Visual Basic

```vb
Property UpsideDown As System.Boolean
```

### C#

```csharp
System.bool UpsideDown {get; set;}
```

### JScript

```
function get,set UpsideDown : System.boolean
```

### Managed Extensions for C++

```
__property System.bool get_UpsideDown();
__property void set_UpsideDown(
   System.bool value
);
```

### C++/CLI

```cpp
property System.bool UpsideDown {
   System.bool get();
   void set (    System.bool value);
}
```

### Property Value

True to display the text of the TextStyle upside down, false to display it right-side up
