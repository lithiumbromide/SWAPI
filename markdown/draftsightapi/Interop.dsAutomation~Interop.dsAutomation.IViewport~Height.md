# Height Property (IViewport)

Gets or sets the height of this selected Viewport.


```csharp

```


```
__property System.double get_Height();

```

### C++/CLI

```cpp
property System.double Height {
   System.double get();
   void set (    System.double value);
```

### Property Value
