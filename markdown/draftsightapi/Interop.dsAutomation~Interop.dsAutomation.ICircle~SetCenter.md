# SetCenter Method (ICircle)

Sets the center point of the Circle.

## Syntax

### Visual Basic

```vb
Sub SetCenter( _
   ByVal X As System.Double, _
   ByVal Y As System.Double, _
   ByVal Z As System.Double _
)
```

### C#

```csharp
void SetCenter(
   System.double X,
   System.double Y,
   System.double Z
)
```

### JScript

```
function SetCenter(
   X : System.double,
   Y : System.double,
   Z : System.double
);
```

### Managed Extensions for C++

```
void SetCenter(
   System.double X,
   System.double Y,
   System.double Z
)
```

### C++/CLI

```cpp
void SetCenter(
   System.double X,
   System.double Y,
   System.double Z
)
```

### Parameters

- `X`: x coordinate of the center point
- `Y`: y coordinate of the center point
- `Z`: z coordinate of the center point
