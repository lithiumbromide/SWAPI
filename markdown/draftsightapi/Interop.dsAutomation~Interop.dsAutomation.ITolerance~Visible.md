# Visible Property (ITolerance)

Gets or sets whether to show the geometric Tolerance in the drawing.

### C++/CLI

```cpp

   System.bool get();
   void set (    System.bool value);
```

### Property Value

True to show the geometric Tolerance in the drawing, false to hide it
