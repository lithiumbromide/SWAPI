# GetMessageFolder Method (IApplication)

Gets the path of DraftSight's **messages** folder.

## Syntax

### Visual Basic

```vb
Function GetMessageFolder() As System.String
```

### C#

```csharp
System.string GetMessageFolder()
```

### JScript

```
function GetMessageFolder() : System.String;
```

### Managed Extensions for C++

```
System.string* GetMessageFolder();
```

### C++/CLI

```cpp
System.String^ GetMessageFolder();
```

### Return Value

Path of DraftSight's **messages** folder

## Remarks

In a typical DraftSight installation, this path is **C:\Program Files\Dassault Systemes\DraftSight\bin\messages**.
