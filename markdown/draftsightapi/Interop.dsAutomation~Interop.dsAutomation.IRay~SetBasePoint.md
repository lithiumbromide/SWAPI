# SetBasePoint Method (IRay)

Sets the base (start) point for the Ray.

### Parameters

- `X`: x coordinate of the base point for the Ray
- `Y`: y coordinate of the base point for the Ray
- `Z`: z coordinate of the base point for the Ray
