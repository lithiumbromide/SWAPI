# GetLanguage Method (IApplication)

Gets the name of the language supported by this DraftSight installation.

## Syntax

### Visual Basic

```vb
Function GetLanguage() As dsLanguage_e
```

### C#

```csharp
dsLanguage_e GetLanguage()
```

### JScript

```
function GetLanguage() : dsLanguage_e;
```

### Managed Extensions for C++

```
dsLanguage_e GetLanguage();
```

### C++/CLI

```cpp
dsLanguage_e GetLanguage();
```

### Return Value

Name of the language supported by this DraftSight installation as defined in [dsLanguage_e](Interop.dsAutomation~Interop.dsAutomation.dsLanguage_e.html)
