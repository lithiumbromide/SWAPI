# SetVertex4Coordinate Method (ITrace)

Sets the x, y, and z coordinates for the fourth vertex for this Trace.

## Syntax

### Visual Basic

```vb
Sub SetVertex4Coordinate( _
   ByVal X As System.Double, _
   ByVal Y As System.Double, _
   ByVal Z As System.Double _
)
```

### C#

```csharp
void SetVertex4Coordinate(
   System.double X,
   System.double Y,
   System.double Z
)
```

### JScript

```
function SetVertex4Coordinate(
   X : System.double,
   Y : System.double,
   Z : System.double
);
```

### Managed Extensions for C++

```
void SetVertex4Coordinate(
   System.double X,
   System.double Y,
   System.double Z
)
```

### C++/CLI

```cpp
void SetVertex4Coordinate(
   System.double X,
   System.double Y,
   System.double Z
)
```

### Parameters

- `X`: x coordinate of the fourth vertex
- `Y`: y coordinate of the fourth vertex
- `Z`: z coordinate of the fourth vertex
