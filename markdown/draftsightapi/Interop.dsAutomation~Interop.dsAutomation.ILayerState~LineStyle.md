# LineStyle Property (ILayerState)

Gets or sets whether to save or restore the LineStyle Layer property.

## Syntax

### Visual Basic

```vb
Property LineStyle As System.Boolean
```

### C#

```csharp
System.bool LineStyle {get; set;}
```

### JScript

```

```

### Managed Extensions for C++

```
__property System.bool get_LineStyle();
__property void set_LineStyle(
   System.bool value
);
```

### C++/CLI

```cpp
property System.bool LineStyle {
   System.bool get();
   void set (    System.bool value);
}
```

### Property Value

True to save or restore the LineStyle Layer property, false to not
