# UpsideDown Property (IAttributeInstance)

Gets or sets whether to display the BlockAttribute instance upside down.

### C++/CLI

```cpp

   System.bool get();
   void set (    System.bool value);
```

### Property Value

True to display the BlockAttribute instance upside down, false to display right-side up
