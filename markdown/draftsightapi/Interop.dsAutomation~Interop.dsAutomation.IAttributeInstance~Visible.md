# Visible Property (IAttributeInstance)

Gets or sets whether to show the BlockAttribute in Block references.

## Syntax

### Visual Basic

```vb
Property Visible As System.Boolean
```

### C#

```csharp
System.bool Visible {get; set;}
```

### JScript

```
function get,set Visible : System.boolean
```

### Managed Extensions for C++

```
__property System.bool get_Visible();
__property void set_Visible(
   System.bool value
);
```

### C++/CLI

```cpp
property System.bool Visible {
   System.bool get();
   void set (    System.bool value);
}
```

### Property Value

True to show the BlockAttribute in Block references, false to hide it
