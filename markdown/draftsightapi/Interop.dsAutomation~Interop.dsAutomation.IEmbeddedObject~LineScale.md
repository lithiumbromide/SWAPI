# LineScale Property (IEmbeddedObject)

Gets or sets the scale factor for the embedded object's [LineStyle](Interop.dsAutomation~Interop.dsAutomation.ILineStyle.html).

```

```

### C++/CLI

```cpp

   System.double get();
   void set (    System.double value);
}
```

### Property Value

Scale factor for the embedded object's LineStyle
