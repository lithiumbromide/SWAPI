# IsOn Property (IViewport)

Gets or sets whether the Viewport is displayed in the graphics area.

## Syntax

### Visual Basic

```vb
Property IsOn As System.Boolean
```

### C#

```csharp

```

### JScript

```

```

### Managed Extensions for C++

```
__property System.bool get_IsOn();
__property void set_IsOn(
   System.bool value
);
```

### C++/CLI

```cpp
property System.bool IsOn {
   System.bool get();
   void set (    System.bool value);
}
```

### Property Value

True if the Viewport is displayed in the graphics area, false if not
