# Create Rectangular Viewport Example (JS)

## Create Rectangular Viewport Example (JavaScript)

| This example shows how to create a rectangular Viewport. Start DraftSight and open a drawing. Click Create Viewport . A Viewport is created in the lower-left corner of Sheet2. Locate the Viewport on Sheet2 in the DraftSight drawing. NOTES: Errors are printed to Output. To recreate this example: Right-click the topic and select to view the source. Save the file as an HTML file. Open the HTML file in your web browser.
