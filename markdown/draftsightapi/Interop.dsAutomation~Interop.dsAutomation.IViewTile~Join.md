# Join Method (IViewTile)

Joins this ViewTile with the specified ViewTile.

## Syntax

### Visual Basic

```vb
Sub Join( _
   ByVal ViewTile As ViewTile _
)
```

### C#

```csharp
void Join(
   ViewTile ViewTile
)
```

### JScript

```
function Join(
   ViewTile : ViewTile
);
```

### Managed Extensions for C++

```
void Join(
   ViewTile* ViewTile
)
```

### C++/CLI

```cpp
void Join(
   ViewTile^ ViewTile
)
```

### Parameters

- `ViewTile`: [ViewTile](Interop.dsAutomation~Interop.dsAutomation.IViewTile.html) to which to join this ViewTile

## Remarks

The ViewTiles to join must be adjacent to one another.
