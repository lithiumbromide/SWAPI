# FrozenThawed Property (ILayerState)

Gets or sets whether to save or restore the Freeze/Thaw Layer property.

### C++/CLI

```cpp

   System.bool get();
   void set (    System.bool value);
```

### Property Value

True to save or restore the Freeze/Thaw Layer property, false to not
