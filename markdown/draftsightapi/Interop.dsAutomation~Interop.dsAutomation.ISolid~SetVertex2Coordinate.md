# SetVertex2Coordinate Method (ISolid)

Sets the coordinates of the second vertex of the 2D Solid.

## Syntax

### Visual Basic

```vb
Sub SetVertex2Coordinate( _
   ByVal X As System.Double, _
   ByVal Y As System.Double, _
   ByVal Z As System.Double _
)
```

### C++/CLI

```cpp
void SetVertex2Coordinate(
   System.double X,
   System.double Y,
   System.double Z
)
```

### Parameters

- `X`: x coordinate of the second vertex
- `Y`: y coordinate of the second vertex
- `Z`: z coordinate of the second vertex
