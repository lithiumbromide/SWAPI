You can [create](Interop.dsAutomation~Interop.dsAutomation.IApplication~CreateTracker.html) a tracker and [add](Interop.dsAutomation~Interop.dsAutomation.ICommandMessage~AddTracker.html) it to any of your programs that use command message prompts. A tracker adds a temporary entity to the cursor in the graphics window during command window prompting.
