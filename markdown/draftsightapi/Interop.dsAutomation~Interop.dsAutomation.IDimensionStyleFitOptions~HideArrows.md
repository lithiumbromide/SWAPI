# HideArrows Property (IDimensionStyleFitOptions)

Gets or sets whether to hide or show arrows that do not fit inside the extension lines.

## Syntax

### Visual Basic

```vb

```

### C#

```csharp

```

### JScript

```

```

### Managed Extensions for C++

```

__property void set_HideArrows(
   System.bool value
);
```

### C++/CLI

```cpp
property System.bool HideArrows {
   System.bool get();
   void set (    System.bool value);
}
```

### Property Value

True to hide the arrows that do not fit inside the extension lines, false to show the arrows
