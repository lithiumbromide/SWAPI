# IDictionary Interface

Allows access to the [named-objects dictionary](Dictionaries.htm) of a drawing.

## Syntax

### Visual Basic

```vb
Public Interface IDictionary
```

### C#

```csharp
public interface IDictionary
```

### JScript

```
public interface IDictionary
```

### Managed Extensions for C++

```
public __gc __interface IDictionary
```

### C++/CLI

```cpp
public interface class IDictionary
```

## Remarks

Dictionaries associate unique names with unique objects of any type. To store data in dictionaries, use the [IXRecord](Interop.dsAutomation~Interop.dsAutomation.IXRecord.html) interface.

To see which interfaces support dictionaries, see the Accessors section or open the object model.
