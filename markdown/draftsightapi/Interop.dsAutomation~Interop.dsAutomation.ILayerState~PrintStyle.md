# PrintStyle Property (ILayerState)

Gets or sets whether to save or restore the PrintStyle Layer property.

## Syntax

### Visual Basic

```vb
Property PrintStyle As System.Boolean
```

### C#

```csharp
System.bool PrintStyle {get; set;}
```

### JScript

```
function get,set PrintStyle : System.boolean
```

### Managed Extensions for C++

```
__property System.bool get_PrintStyle();
__property void set_PrintStyle(
   System.bool value
);
```

### C++/CLI

```cpp
property System.bool PrintStyle {
   System.bool get();
   void set (    System.bool value);
}
```

### Property Value

True to save or restore the PrintStyle Layer property, false to not
