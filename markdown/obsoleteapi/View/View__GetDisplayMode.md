# View::GetDisplayMode

This method is obsolete and been superseded by [View::GetDisplayMode2](sldworksAPI.chm::/View/View__GetDisplayMode2.htm).

Description

This method determines the current display mode of the drawing view.

Syntax (OLE Automation)

retval = View.GetDisplayMode ()

| Return: | (long) retval | Current display mode of the drawing view as defined in swDisplayMode_e |
| --- | --- | --- |

Syntax (COM)

status = View->GetDisplayMode ( &retval )

| Output: | (long) retval | Current display mode of the drawing view as defined in swDisplayMode_e |
| --- | --- | --- |
| Return: | (HRESULT) status | S_OK if successful |
