# Face::ResetPropertyExtension

This method is obsolete and has been superseded by [Face2::ResetPropertyExtension](sldworksAPI.chm::/Face2/Face2__ResetPropertyExtension.htm).

Description

This method clears out all values stored in the property extension.

Syntax (OLE Automation)

void Face.ResetPropertyExtension ()

Syntax (COM)

status = Face->ResetPropertyExtension ( )

| Return: | (HRESULT)status | S_OK if successful |
| --- | --- | --- |

Remarks

This method is unsupported for faces obtained from reference surface bodies.
