# DesignTable::EditTable

This method is obsolete and has been superseded by [DesignTable::EditTable2](sldworksAPI.chm::/DesignTable/DesignTable__EditTable2.htm).

Description

This method lets you edit the design table.

Syntax (OLE Automation)

DesignTable.EditTable ()

Syntax (COM)

status = DesignTable->EditTable ( )

| Return: | (HRESULT) status | S_OK if successful |
| --- | --- | --- |

Remarks

You can change the parameter values in the cells, add rows for additional configurations, or add columns to control additional parameters.
