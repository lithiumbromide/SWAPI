# Feature::IsSuppressed

This method is obsolete and has been superseded by [Feature::IsSuppressed2](sldworksAPI.chm::/Feature/Feature__IsSuppressed2.htm).

Description

This method determines whether or not the feature is suppressed.

Syntax (OLE Automation)

retval = Feature.IsSuppressed ()

| Return: | (VARIANT_BOOL) retval | TRUE if this feature is suppressed, FALSE if it is not |
| --- | --- | --- |

status = Feature->IsSuppressed ( &retval )

| Output: | (VARIANT_BOOL) retval | TRUE if this feature is suppressed, FALSE if it is not |
| --- | --- | --- |
| Return: | (HRESULT) - status | S_OK if successful |
