# Feature::IsBase

This method is obsolete and has been superseded by [Feature::IsBase2](sldworksAPI.chm::/Feature/Feature__IsBase2.htm).

Description

This method determines whether this feature is a base feature.

Syntax (OLE Automation)

bBase = Feature.IsBase ( )

| Output: | (VARIANT_BOOL) bBase | TRUE if this is a base feature, FALSE if not |
| --- | --- | --- |

Syntax (COM)

status = Feature->IsBase ( &bBase )

| Output: | (VARIANT_BOOL) bBase | TRUE if this is a base feature, FALSE if not |
| --- | --- | --- |
| Return: | (HRESULT) status | S_OK if successful |
