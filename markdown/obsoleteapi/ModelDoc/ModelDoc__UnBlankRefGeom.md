# ModelDoc::UnBlankRefGeom

This method is obsolete and has been superseded by [ModelDoc2::UnBlankRefGeom](sldworksAPI.chm::/ModelDoc2/ModelDoc2__UnBlankRefGeom.htm).

Description

This method shows the selected reference geometry in the graphics window.

Syntax (OLE Automation)

void ModelDoc.UnBlankRefGeom ()

Syntax (COM)

status = ModelDoc->UnBlankRefGeom ( )

| Return: | (HRESULT) status | S_OK if successful |
| --- | --- | --- |

Remarks

If you select a reference plane and call this method, the plane will be visible in the graphics area. This method has the same effect as selecting an item and choosing Show on your-right mouse button menu.
