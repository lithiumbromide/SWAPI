# ModelDoc::EntityProperties

This method is obsolete and has been superseded by [ModelDoc2::EntityProperties](sldworksAPI.chm::/ModelDoc2/ModelDoc2__EntityProperties.htm).

Description

This method displays the Properties dialog for the selected edge or face. This is the Properties menu selection that appears on a context-sensitive (also called right-mouse button or shortcut) menu for an edge or face.
