# ModelDoc::GraphicsRedraw2

This method is obsolete and has been superseded by [ModelDoc2::GraphicsRedraw2](../ModelDoc2/ModelDoc2__GraphicsRedraw2.htm).

Description

This method repaints the current graphics view. This method is similar to ModelDoc::WindowRedraw except that it updates only the current graphics view.
