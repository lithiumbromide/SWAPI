# RegenPostNotify - PartDoc Event

This event is obsolete and has been superseded by PartDoc event [RegenPostNotify2](sldworksAPI.chm::/PartDocEvents/PartDocEvents__RegenPostNotify2.htm).

Description

Post-notifies the user program when a part document has been rebuilt.

status = RegenPostNotify ( )

| Return: | (HRESULT) status | S_OK if successful |
| --- | --- | --- |

Remarks
