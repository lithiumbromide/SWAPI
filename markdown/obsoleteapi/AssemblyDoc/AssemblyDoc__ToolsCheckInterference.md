# AssemblyDoc::ToolsCheckInterference

This method is obsolete and has been superseded by [AssemblyDoc::ToolsCheckInterference2](sldworksAPI.chm::/AssemblyDoc/AssemblyDoc__ToolsCheckInterference2.htm).

Description

This method performs an interference check on the assembly.

Syntax (OLE Automation)

void AssemblyDoc.ToolsCheckInterference ()

Syntax (COM)

status = AssemblyDoc->ToolsCheckInterference ( )

| Return: | (HRESULT)status | S_OK if successful |
| --- | --- | --- |

Remarks

This method performs an interference check on the currently selected components in the assembly and displays the Interference Volumes dialog box.
