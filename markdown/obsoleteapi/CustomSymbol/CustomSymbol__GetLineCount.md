# CustomSymbol::GetLineCount

This method is obsolete and has been superseded by [Note::GetLineCount](sldworksAPI.chm::/Note/Note__GetLineCount.htm).

This method gets number of line items in this custom symbol.

Syntax (OLE Automation)

retval = CustomSymbol.GetLineCount ()

| Return: | (long) retval | Number of lines |
| --- | --- | --- |

Syntax (COM)

status = CustomSymbol->GetLineCount ( &retval )

| Output: | (long) retval | Number of lines |
| --- | --- | --- |
| Return: | (HRESULT) status | S_OK if successful |
