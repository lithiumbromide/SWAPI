# CustomSymbol::GetNoteCount

This method is obsolete and has been superseded by [BlockDefinition::GetNoteCount](../BlockDefinition/BlockDefinition__GetNoteCount.htm).

| Output: | (long) retval | Number of notes |
| --- | --- | --- |
