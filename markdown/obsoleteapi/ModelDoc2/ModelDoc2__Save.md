# ModelDoc2::Save

This method is obsolete and has been superseded by [ModelDoc2::Save2](ModelDoc2__Save2.htm).

Description

This method saves the current document using its current name. If it is a new document, use ModelDoc2::SaveAs instead.

Syntax (OLE Automation)

void ModelDoc2.Save ()
