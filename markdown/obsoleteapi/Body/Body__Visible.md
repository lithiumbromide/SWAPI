# Body::Visible

This property is obsolete and has been superseded by [Body2::Visible](sldworksAPI.chm::/Body2/Body2__Visible.htm).

Description

This property gets the visibility of this body.

Syntax (OLE Automation)

retval = Body.Visible ( )

| Return: | (BOOL) retval | TRUE if the body is visible, FALSE if it is hidden |
| --- | --- | --- |

Syntax (COM)

status = Body->Visible ( &retval )

| Output: | (VARIANT_BOOL) retval | TRUE if the body is visible, FALSE if it is hidden |
| --- | --- | --- |
| Return: | (HRESULT) status | S_OK if successful |
