# PartDoc::SaveToFile

This method is obsolete and has been superseded by [PartDoc::SaveToFile2](sldworksAPI.chm::/PartDoc/PartDoc__SaveToFile2.htm).

Description

This method saves the selected surfaces or solid bodies in the Surface Bodies or Solid Bodies folders or sub-folders to part files.
