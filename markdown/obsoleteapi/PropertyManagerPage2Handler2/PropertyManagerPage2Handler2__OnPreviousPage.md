retval = PropertyManagerPage2Handler2.OnPreviousPage ( )

| Output: | (VARIANT_BOOL) retval | TRUE if the previous page displays successfully, FALSE if not |
| --- | --- | --- |

| Output: | (VARIANT_BOOL) retval | TRUE if the previous page displays successfully, FALSE if not |
| --- | --- | --- |
