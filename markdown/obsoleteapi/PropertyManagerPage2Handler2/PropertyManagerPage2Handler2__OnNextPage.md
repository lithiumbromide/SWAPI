# PropertyManagerPage2Handler2::OnNextPage

This method is obsolete and has been superseded by [PropertyManagerPage2Handler3::OnNextPage](../PropertyManagerPage2Handler3/PropertyManagerPage2Handler3__OnNextPage.htm).

Description

This method is called when the end-user clicks the Next button on the PropertyManager.

Syntax (OLE Automation)

retval = PropertyManagerPage2Handler2.OnNextPage ( )

| Output: | (VARIANT_BOOL) retval | TRUE if the next page displays successfully, FALSE if not |
| --- | --- | --- |

Syntax (COM)

status = PropertyManagerPage2Handler2->OnNextPage ( &retval )

| Output: | (VARIANT_BOOL) retval | TRUE if the next page displays successfully, FALSE if not |
| --- | --- | --- |
| Return: | (HRESULT) status | S_OK if successful |
