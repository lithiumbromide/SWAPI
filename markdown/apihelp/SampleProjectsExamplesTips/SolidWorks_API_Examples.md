# SOLIDWORKS API Examples, Sample Projects, and Tips

To locate SOLIDWORKS examples in the Help, use the index tab.

Examples are grouped by language on the Index tab. Type:

- C# examples to see available C# examples.
- C++/CLI examples to see available managed C++ examples.
- Visual Basic .NET (VB.NET) examples to see available VB.NET examples.
- VBA examples to see available Visual Basic for Applications (VBA) examples.
- C++ examples to see available unmanaged C++ examples.

Examples are also linked to relevant reference topics. See the Example section in a reference topic.

The SOLIDWORKS API Support web page, which is part of the [SOLIDWORKS website](http://www.solidworks.com), provides you access to additional API examples, sample projects, tips, discussion forum, knowledge base, etc.

NOTE: You must be connected to the internet to view the SOLIDWORKS API Support web page and SOLIDWORKS website.
