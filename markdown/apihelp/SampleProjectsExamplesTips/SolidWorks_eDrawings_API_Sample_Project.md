# eDrawings API Sample Project

The eDrawings API sample projects show how to create eDrawings API applications in Microsoft Visual Studio and other types of applications that support ActiveX controls. You can obtain the eDrawings API SDK, which contains the eDrawings API sample projects, from [SOLIDWORKS API Support](../ContactingAPISupport/Contacting_API_Support.htm).
