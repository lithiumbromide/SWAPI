# eDTexture Class

| See Also | Example | Accessors | Availability |
| --- | --- | --- | --- |

Contains bitmap coordinate mapping information and is contained by an [eDAppearance](../eDAppearance/eDAppearance_Class.htm).

You create an eDTexture using [eDScene::CreateTexture](../eDScene/eDScene_Class.htm) and then add it to an appearance through the constructor of [eDAppearance](../eDAppearance/eDAppearance_Class.htm).

NOTE: The eDTexture header file is not distributed because you will not call any of its methods.
